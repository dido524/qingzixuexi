# 北师大版五年级上册数学课程知识图（第一版）

## 目的与边界

以家长提供的三张教材封面、扉页和目录照片为本学期学校数学课程的证据，建立可查看、可逐年扩展的课程骨架，而不把目前模型从作业中抽取的零散标签冒充教材知识体系。学校课程、兴趣班超前内容、未来六年级和初中教材应可共存；本版只录入这本书目录中可核实的内容，不虚构其内页课时或未来教材。

现有 SQLite 的题目、家长确认、掌握度仍是学习事实来源；课程图只描述课程结构与经过显式标注的建议关系，不改变任何判卷事实或复习优先级。

## 证据

- `C:\Users\Home\Downloads\20260919_165508.jpg`：五年级上册、北京师范大学组织编写。
- `C:\Users\Home\Downloads\20260919_165515.jpg`：两页目录，八个编号单元，两个综合实践、一个“数学好玩”和总复习；各起始页见版本化目录数据。
- 封面上的“2024”是审定标识，并不自动解释为本册的印次或出版日期。网上仍有标为“北师大版（2024）”却列旧目录的页面，本版以实拍目录为准。

## 选用方案

1. **仅在现有首页增加静态清单**：实现快，但关系无法复用，Obsidian 看不到结构化链接。
2. **版本化课程目录 + 双视图导出（选用）**：保存课程、节点、关系的稳定 ID 和证据；导出离线 HTML 关系图与 Obsidian Markdown。未来新增册次只增加目录数据，渲染器不写死“五年级上册”。
3. **立刻将所有历史知识点自动映射到新课程**：看似丰富，但现有 172 个标签混有待确认题和兴趣班内容，名称匹配会造成假归类，因此本版不采用。

## 数据约定

- 一个 `catalog_id` 标识一本教材/课程版本；包含学科、学段、年级、上下册、出版社、版本线、学习来源（学校/兴趣班）、来源证据。
- 节点有稳定的 `node_id`、显示名、类型（单元/综合实践/数学好玩/复习）、顺序和起始页；ID 不从可变标题推导，重命名不破坏链接。
- 关系有 `from`、`to`、类型及 `basis`；目录顺序是事实，先修/应用是教学整理建议，页面必须标明两者区别。初版只建立明显且可解释的少量关系，不把目录邻接误作先修。
- 解析器拒绝重复 ID、悬空边、越界页码、未知类型、跨课程隐式连边和不安全路径；读者可安全扩展新目录。以后可显式增加跨册或兴趣班与学校课程之间的边。
- 课本照片作为用户知识库中的私有证据副本保存，不进入公开代码仓库；代码目录仅保存来源文件名、SHA-256 和人工核实的目录转录。

## 呈现与联动

- 首页“知识点地图 · 重点短板”增加清晰入口“数学课程知识图（北师大版五年级上册）”；原短板数据照旧。
- 离线 HTML 用分层卡片显示本学期主线、起始页、跨单元关系，并清楚区分“教材目录确认”和“整理建议”。无需安装 Obsidian 即可使用。
- Obsidian 兼容 Markdown 课程首页及节点笔记以普通相对 Markdown 链接连接。节点文件名只用稳定 ID，笔记标题用可读教材标题，避免教材改名造成链接失效；导出不依赖社区插件。
- 学生现有题目与知识统计不自动按相似名称挂载。后续提供“待分类”人工审核后再建立题目/知识点到课程节点的显式映射，兴趣班标签也允许落在独立课程线。

## 发布与错误处理

- 课程导出先生成全部目标文件，再让首页链接出现；纳入现有发布清单，保证文件丢失可重建。若课程数据校验失败，发布报错且旧事实数据库不变。
- 再运行必须幂等；`系统课程总览.md` 与 `系统-节点ID.md` 是可重建课程结构，`我的课程笔记.md` 与 `我的-节点ID.md` 只在首次创建，家长修改后程序永不重写。已生成过的旧版 `课程总览.md` 和 `节点ID.md` 原样保留，并从新版系统笔记提供入口。原图和旧记录也不覆盖或删除。
- 家长笔记不进入内容哈希清单；发布状态只检查其链接目标是否存在。若文件被删除，下次知识库刷新/发布会重建空白笔记，不会重写其他仍存在的家长笔记。
- 程序从版本化目录文件夹发现所有课程；增加兴趣班或下一年级目录数据后，首页和发布清单自动包含新课程，不以书名或年级硬编码入口。
- 当前真实数据根目录仍是家长指定的 `C:\晴子知识库\5th grade`。目录格式和渲染器可以区分新年级，但六年级/初中正式入库之前，还需单独设计跨年级根目录和历史记录迁移；第一版不擅自移动现有数据。
- 本版不更改默认模型调用、扫描/批改流程、成绩口径，也不安装特定 LLMWiki。

## 验收

1. 目录节点名称、数量、顺序和页码与实拍目录逐一吻合；旧版网录目录不得混入。
2. 悬空关系/重复 ID/不安全来源路径的目录校验测试失败；新增兴趣班或下一年级的最小示例可由同一个渲染器导出。
3. HTML 与 Markdown 所有内部链接落在知识库根目录下且真实存在；原首页短板与已确认题目数保持不变。
4. 完整测试、打包安全检查和实机文件验收通过后，才向用户报告可用；安装如需替换运行中的程序，先确认其已关闭并备份数据库。
