# 晴子学习助手：增量学情报告、针对性模拟卷与打印设计

日期：2026-09-17  
状态：已与用户确认，待实施规划

## 1. 目标与范围

本功能把现有的作业、试卷、错题和知识点数据转化为两个可直接使用的成果：

1. 随历史样本增长而逐步丰富的学情报告；
2. 根据当前短板生成、打印、回收并复测的针对性模拟试卷。

桌面程序新增“学习与复习中心”，集中完成生成、历史查看、打印和复测追踪。报告面向孩子与家长分别呈现：孩子版清晰、温和、容易理解，但不使用低幼卡通表达；家长版保留完整数据、证据和判断边界。

本功能继续服务一个五年级学生及语文、数学、英语三个学科。不增加多人账号、云同步、学校系统连接、在线分享或全科课程题库。

## 2. 设计原则

- **事实与表达分离**：本地程序计算样本数、掌握度、错误频率、趋势和组卷权重；模型只负责自然语言表达与新题草拟。
- **增量而非覆盖**：每次报告都是不可变的历史快照，同时更新“最新报告”入口。
- **证据不足时少说**：小样本必须显示“初步观察”或“样本不足”，不得把一次错误写成稳定短板。
- **可追溯**：报告结论和模拟卷出题原因可以追溯到学科、知识点、历史题目、页码及人工确认状态。
- **孩子可接受**：描述行为和下一步练习，不给孩子贴“差”“粗心”“能力弱”等标签。
- **打印安全**：学生卷、答题纸、答案解析和家长报告分文件、分按钮，不能默认混合打印。
- **家长最终把关**：模型生成的试卷必须先预览确认，未经确认不能进入正式打印和复测统计。

## 3. 用户流程

### 3.1 生成报告

1. 用户在主界面点击“学习与复习”。
2. 程序打开较大的“学习与复习中心”，默认显示当前可用证据量和最近一次报告。
3. 用户点击“生成新报告”。
4. 程序读取数据库当前快照，与最近一次已完成报告的快照比较。
5. 程序生成孩子版和家长版 HTML，并保存本次结构化快照。
6. 用户可以打开、打印任一版本，或从历史列表重新查看旧版本。

### 3.2 生成模拟卷

1. 用户选择学科、考试范围、答题时长、难度、题量，以及是否包含作文、阅读等主观题。
2. 程序展示建议的组卷蓝图，包括目标知识点、题型和比例。
3. 用户点击生成，程序使用已确认的历史证据和组卷蓝图调用模型。
4. 程序完成结构校验和第二遍审题，生成试卷预览。
5. 用户选择“确认可打印”或“重新生成”；只有确认后的试卷才能打印。
6. 用户分别打印学生卷、答题纸和答案解析。

### 3.3 完成复测

1. 每份正式模拟卷及答题纸都印有唯一试卷编号和稳定题号。
2. 孩子完成后，用户像普通作业一样拍摄并分析。
3. 模型识别打印在页面上的试卷编号和题号；本地程序再次校验该编号确实存在。
4. 程序将本次作答关联到对应模拟卷，作为新的有效学习证据。
5. 下一份报告展示“上次建议练习—模拟卷复测—当前结果”的变化，但仍保留原始历史记录。

## 4. 方案选择

采用“确定性事实层 + 受约束模型层”的混合方案：

- 报告事实、变化比较、证据等级和组卷权重由本地代码产生；
- 孩子版说明和模拟题由当前已登录的 Codex CLI 生成；
- 模型输入是经过裁剪的结构化学习资料，不提交整个知识库，也不提交无关个人信息或全量原图；
- 报告模型不可用时，程序使用本地模板生成完整但较简洁的报告；
- 模拟题模型不可用时保留本次草稿设置并允许重试，不发布半成品。

报告模型只能返回受 Schema 约束的标题、说明段落、行动建议和所引用的证据编号。本地程序拒绝不存在的知识点、样本数、趋势或证据编号，并负责把通过校验的文字与确定性统计组合成最终页面。模型不能直接生成整份 HTML，也不能修改统计事实。

不采用完全由模型自由总结的方案，因为同一数据可能产生前后不一致的结论。也不采用纯模板组卷，因为题目变化、语文阅读和英语表达的质量会明显受限。

## 5. 增量学情快照

每次报告保存一个完整、不可变的结构化快照。快照至少包含：

- 生成时间和纳入证据的截止时间；
- 各学科资料数、有效题目数、待确认数及不同学习日期数；
- 每个知识点的正确、错误、部分正确、复测次数、最近出现时间、趋势和复习优先级；
- 常见错误类型及其证据数量；
- 自上次报告以来新增、改善、下降、首次出现和已稳定的知识点；
- 本次建议行动及其来源证据。

增量变化通过“当前快照与上一份已完成快照比较”得到，而不是仅依赖文件时间。这样即使家长后来修正一道旧题，下一份报告也能正确反映变化。

证据分级按学科独立计算：

- 没有有效题目：只显示尚无足够资料；
- 少于 10 道有效题，或只来自 1 个学习日期：标记“初步观察”；
- 10—29 道且覆盖至少 2 个学习日期：标记“逐步形成”；
- 至少 30 道且覆盖至少 3 个学习日期：标记“趋势较稳定”。

“有效题目”沿用现有掌握度规则：家长确认的题目，或非待确认且置信度至少为 0.80 的题目。报告显示真实样本数，证据等级只约束措辞，不把阈值包装成教育学结论。

## 6. 孩子版报告

孩子版以一页 A4 为首要目标；数据充分时允许第二页，但首屏和第一页必须保留核心内容：

- 本阶段完成了什么；
- 新出现的进步；
- 当前最值得练习的 1—3 个知识点；
- 容易重复出现的 1—2 种做题习惯或错误模式；
- 下一阶段三个具体、可完成的小目标；
- 一句中性、真实的总结。

措辞使用“下一步练习”“正在形成”“再检查一次”等表达，不显示排名，不使用夸张鼓励，也不隐藏证据不足。颜色使用克制的蓝、绿和暖灰，字号、行距和卡片层级以阅读清晰为先，不使用幼儿化插画。

## 7. 家长版报告

家长版提供完整决策依据：

- 累计情况与本次增量；
- 分学科掌握情况、样本规模和证据等级；
- 知识点优先级、错误类型、近期趋势和最近一次表现；
- 反复错误、已经改善和需要继续验证的项目；
- 对应原题、分析记录及页码链接；
- 待家长确认的数据，不纳入统计的原因；
- 建议的复习顺序、频次和模拟卷配置。

掌握率旁必须显示样本数。样本不足时不使用大面积红色告警，也不把百分比单独作为结论。

## 8. 针对性组卷蓝图

默认试卷按目标题量分配：

- 约 50%：复习优先级最高、近期仍出错或下降的主要短板；
- 约 30%：与主要短板在同一题目或资料中共同出现、或共享常见错误类型的相关知识点；
- 约 20%：已有较好表现的知识点，用于检验稳定性并保持合理难度节奏。

整数题量通过确定性取整分配，总题数必须与用户选择一致。若某一类别证据不足，其份额依次回流到主要短板和相关知识点，并在组卷说明中披露。没有任何已确认短板时，程序不声称生成“针对性”试卷，而是提示继续积累资料或由家长明确选择复习范围。

候选证据必须满足以下条件：

- 不处于 `needs_review`；
- 来自家长确认，或模型置信度至少为 0.80；
- 位于用户选择的学科和考试范围内；
- 能追溯到现存文档、题号和知识点。

模型接收知识点、常见错因、题型分布、代表性题干摘要和参考答案，但不得直接复制原错题。生成题目必须保持五年级难度和用户指定范围。

## 9. 模拟卷生成与校验

模型返回受 JSON Schema 约束的结构化试卷，至少包含：

- 试卷编号、学科、建议时长、总分和难度；
- 稳定题号、题型、题干、分值和答题区域要求；
- 目标知识点、出题原因和蓝图类别；
- 标准答案、评分要点和解析；
- 主观题的可接受答案范围或评分量表。

本地校验必须检查：题号唯一、题数正确、总分正确、字段完整、答案不出现在学生卷、目标知识点来自蓝图、文本可安全输出、题目间不存在明显重复。随后进行一次独立审题调用，检查答案一致性、题意歧义、超出年级范围和无法作答的问题；允许一次受约束修复。仍不能通过的试卷保持失败草稿，不进入打印状态。

模型校验不能替代家长判断。正式状态为：`draft`、`validating`、`needs_parent_approval`、`approved`、`failed`。只有 `approved` 可以进入打印中心。

## 10. 复测关联与知识更新

分析结果契约增加可为空的 `source_exam_id`，题目增加可为空的 `source_exam_question_id`。普通作业均返回空值；识别到模拟卷编号时返回打印内容中的编号。

本地程序必须验证：

- 试卷编号存在且状态为 `approved`；
- 学科一致；
- 题号存在于该试卷；
- 同一道扫描题不能关联多个模拟题。

验证失败时按普通资料保存并进入待确认，不猜测关联。验证成功后仍走现有题目、家长复核和知识统计流程，同时记录一次模拟卷作答。复测不会覆盖此前错误；报告通过历史证据展示是否改善、是否连续答对以及是否仍需再次检验。

## 11. 数据结构

新增以下持久化实体：

- `report_runs`：报告编号、生成状态、生成时间、上一报告编号、证据截止时间、完整快照 JSON、输出清单及错误代码；
- `exam_runs`：试卷编号、状态、学科、用户配置、组卷蓝图、模型结果、审题结果、输出清单、创建及确认时间；
- `exam_questions`：试卷编号、稳定题号、题型、分值、目标知识点、蓝图类别、题干、答案、解析和评分要点；
- `exam_attempts`：试卷编号、模拟题号、来源文档和来源题号、作答状态及关联时间。

现有 `documents`、`questions`、`knowledge_stats` 和 `effective_questions` 继续是真实学习证据的权威来源。报告快照和试卷记录不能反向改写历史题目结论。

数据库变更使用向前兼容的 `CREATE TABLE IF NOT EXISTS` 和显式迁移测试。旧数据库升级后，原有拍摄、分析、复核和知识库导出流程必须保持可用。

## 12. 文件结构与发布

新增目录：

```text
C:\晴子知识库\5th grade\
├─ 学习报告\
│  ├─ 最新学情报告.html
│  └─ 2026\09\report-20260917-001\
│     ├─ 孩子版.html
│     ├─ 家长版.html
│     └─ report.json
└─ 模拟试卷\
   └─ 2026\09\QZ-MATH-20260917-001\
      ├─ 学生试卷.html
      ├─ 答题纸.html
      ├─ 答案与解析.html
      ├─ 组卷说明.html
      └─ exam.json
```

所有输出继续使用固定根目录、路径白名单、重解析点检查、暂存目录和原子替换。数据库先记录待发布状态，全部文件成功替换后才标记完成；重启时可以幂等恢复。`report.json` 和 `exam.json` 是阅读与恢复材料，不替代 SQLite 事实层。

知识库首页新增“最新学情报告”和“最近模拟卷”入口，但生成动作只在桌面程序中执行，离线 HTML 仍保持只读。

## 13. 学习与复习中心界面

主窗口新增一个“学习与复习”按钮，打开可缩放的大窗口，避免继续挤压拍摄区底部按钮。窗口包含两个标签页：

### 学情报告

- 当前证据量与证据等级；
- 最近一次报告时间和本次新增样本；
- “生成新报告”按钮；
- 历史报告列表；
- 打开、打印孩子版和打印家长版按钮。

### 模拟试卷

- 学科、范围、时长、难度、题量及主观题选项；
- 组卷蓝图预览；
- 生成进度与可恢复错误；
- 试卷预览、确认可打印、重新生成；
- 历史模拟卷及复测状态；
- 打印学生卷、答题纸、答案解析和组卷说明按钮。

耗时的数据库读取、模型调用和文件发布在现有工作线程中执行。窗口关闭不会终止已安全登记的生成任务；再次打开时恢复状态。

## 14. 打印设计

四类 HTML 输出都包含独立的 A4 打印样式：页边距、页码区域、题目分页控制、答题留白和黑白打印对比度。学生卷不嵌入答案数据；答案解析是单独文件，避免通过查看网页源代码泄漏。

程序中的打印按钮打开对应的专用打印视图，并请求 Windows 默认浏览器显示系统打印对话框。每个打印视图同时保留一个明显的“打印”按钮；若浏览器阻止自动弹出，用户点击该按钮即可调用 `window.print()`。用户可以选择打印机、份数、单双面，也可以使用“另存为 PDF”。程序不绕过对话框直接发送到默认打印机，避免误打答案或浪费纸张。

打印失败不改变报告或试卷状态。每个按钮只绑定一个明确文件；打印学生卷时不会连带打开或打印答案解析。

## 15. 隐私、安全与错误处理

- 报告模型输入只包含结构化统计、知识点、必要的题干摘要和去标识化证据，不发送全量历史图片。
- 组卷模型不得访问文件系统、网络或知识库目录，只接收程序构造的受限 JSON 上下文。
- 模型原始响应保存在该生成任务的应用数据诊断区，不显示给孩子，也不包含密钥。
- 所有 HTML 文本转义，嵌入 JSON 使用安全编码，禁止模型返回任意脚本或本地路径。
- 待确认题目明确计数，但不进入掌握率、趋势或组卷权重。
- 报告生成失败时保留上一份“最新报告”，不发布半份文件。
- 模拟卷生成或审题失败时保留可重试草稿，不允许打印为正式卷。
- 打印浏览器不可用时显示文件路径和恢复建议，不把“文件已生成”误报成“已打印”。

## 16. 测试与验收

采用测试驱动实现，至少覆盖：

1. 空知识库、少样本和充分样本分别产生正确的证据等级与措辞边界。
2. 第二次报告能准确显示相对上次的新增、改善、下降和未变化项目。
3. 家长修正旧题后，新报告通过快照比较反映变化，旧报告保持不变。
4. 孩子版不出现排名、羞辱性标签、原始技术状态或家长专用统计细节。
5. 家长版的每个重点结论都带样本数，并能链接到现有证据。
6. 报告模型不可用时，本地模板仍能生成可读且可打印的两个版本。
7. 默认组卷比例按整数题量正确分配；证据不足时按规则回流并披露。
8. 待确认、低置信度和范围外题目不进入组卷证据。
9. 试卷 Schema、题号、题数、总分、答案隔离和重复题校验均能拒绝坏结果。
10. 未经家长确认的试卷不能打印；确认后的四个打印按钮只打开各自文件。
11. A4 打印样式在常用浏览器打印预览中分页合理，学生卷不包含答案文本或答案 JSON。
12. 模拟卷编号和题号匹配时建立复测关联；伪造、未知或跨学科编号进入待确认。
13. 同一模拟卷扫描任务重复处理不会重复累计 `exam_attempts` 或知识统计。
14. 任一发布步骤失败后可恢复，不覆盖上次有效报告，不留下部分正式试卷。
15. 旧数据库升级后，现有拍摄、混合学科拆分、家长复核、知识库首页和 514 项回归测试继续通过。

端到端验收使用真实数据库完成：先生成并打印一份孩子报告和一份数学模拟卷，再将模拟卷答题页拍摄分析；系统应把作答关联到原试卷，更新知识统计，并在下一份报告中显示相对上一份报告的复测变化。

## 17. 非目标与后续扩展

- 第一阶段不提供联网题库采购或版权题库抓取；
- 不自动评价作文思想内容，也不以单一模型分数替代教师评价；
- 不自动把报告发送到手机、邮箱或云盘；
- 不直接静默打印到默认打印机；
