# 小学数学双视图知识图谱设计

## 目标

把现有以教材单元卡片为主的“课程知识图”升级为同一知识底座上的两个互补视图：

1. **全景脑图**：帮助孩子反复观看“知识从哪里来、彼此怎样连接”，逐渐形成整体认知结构；允许同时看到跨单元、跨学期和跨年级关系，不能退化为逐层展开的一棵目录树。
2. **交互式知识图谱**：帮助家长按年级、教材、训练来源和掌握状态筛选，追踪短板、证据和复习路径。

两个视图只改变呈现方式，共用同一组稳定节点、关系、来源映射和掌握证据。任何节点在两个视图中的名称、状态和统计必须一致。

## 结构依据与边界

稳定主干依据《义务教育数学课程标准（2022年版）》组织为四个领域：数与代数、图形与几何、统计与概率、综合与实践。学段、年级、学期、教材版本不作为根节点，而作为知识点属性和筛选条件，以支持五年级、六年级、初中以及不同教材的连续扩展。

课程标准是规范性骨架；北师大版教材目录、学校作业、计算小超市和补习班课程都是来源层。来源层可以覆盖、训练或补充知识点，但不能自行改变官方知识领域，也不能把培训机构的超前内容标成国家课标要求。

当前北师大版五年级上册的实拍目录仍是本学期教材映射的第一证据。课程标准只给出第三学段（五至六年级）边界，不据此臆测某知识点一定安排在五年级上册。

## 规范化知识层级

```text
小学数学
├─ 数与代数
│  ├─ 数与运算
│  └─ 数量关系
├─ 图形与几何
│  ├─ 图形认识与测量
│  └─ 图形位置与运动
├─ 统计与概率
│  ├─ 数据收集、整理与表达
│  └─ 随机现象与可能性
└─ 综合与实践
   ├─ 主题活动
   └─ 项目学习
```

课程标准的十一项核心素养（数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、数据意识、模型意识、应用意识、创新意识）作为标签和筛选维度，不与四个领域并列成另一套树。

在官方主干之外设置“规范化拓展专题”，容纳补习班、兴趣班和超前材料：

- 数感与计算策略
- 数量关系与应用建模
- 数的性质与初等数论
- 图形与空间推理
- 计数与组合
- 逻辑、规律与解题策略
- 数据、概率与实践探究

拓展节点必须标明来源、适用级别和“非当前课标主干”身份；如果其内容与官方知识点重合，则建立“训练于/应用于”关系而不复制知识点。

## 来源层及可扩展映射

来源实体统一建模，不为任何品牌写死渲染逻辑：

- 学校教材：出版社、版本、年级、学期、单元、课时。
- 计算训练：供应方、系列、级别、月份/册次、天/页。
- 补习班：机构、课程、班型、讲次。
- 学习证据：扫描页、题目、试卷、老师批改、家长确认。

“计算小超市”作为计算训练系列接入。例如“第18天”可同时以 `训练于` 连接小数乘法、运算顺序和估算验算。其他补习班讲次采用同样方式，一讲可以映射多个规范化知识点，一个知识点也可以由多个来源训练。

来源映射分为四种状态：`已确认`、`待确认`、`未匹配`、`疑似跨学科`。只有已确认映射进入掌握度聚合。现有数学统计中疑似英语语法的标签必须隔离，不能显示为数学知识点或影响数学状态。

## 关系类型

知识图谱至少支持以下显式关系：

- `包含`：领域、主题和知识点的层级关系。
- `前置于`：理解后一个知识点所需的基础。
- `深化为`：同一概念跨学段的发展。
- `应用于`：知识在模型、实践或其他知识中的使用。
- `易混淆`：适合并排比较的概念。
- `教材覆盖`：教材单元或课时对应的知识点。
- `训练于`：练习册、计算小超市或补习班讲次训练的知识点。
- `考查于`：题目或试卷实际考查的知识点。
- `掌握证据`：家长确认后的作答结论与知识点之间的关系。

所有非目录事实关系必须记录依据和置信等级。仅靠名称相似生成的关系默认进入待确认，不直接成为正式连线。

## 视图一：全景关联脑图

此视图面向孩子，目标是形成“知识网络”的长期印象，而不是展示管理数据。

- 默认以四大领域组成四个柔和色区，核心主题围绕中心展开。
- 保留层级主枝，同时明确画出跨枝关系，例如“分数—比—比例”“面积—小数乘法”“统计图—百分数”“因数倍数—分数约分通分”。
- 支持按当前学期、当前年级、全部小学三种观看范围切换。
- 教材单元以小徽标附着在知识点旁，不让教材目录占据主结构。
- 掌握稳定的节点保持清晰但降低视觉权重；薄弱节点加粗外圈，前置缺口沿连线形成可见路径。
- 默认隐藏题目级明细，点击节点才显示“我在哪里学过”“和什么有关”“最近掌握情况”。
- 支持缩放、拖动、搜索、全屏、打印和恢复全貌；打印版自动生成适合横向纸张的静态快照。
- 为控制复杂度，默认只显示重要跨主题关系；“显示全部关系”是可选开关。

该视图不是单纯的径向树。层级边负责建立骨架，横向关系边负责建立真正的知识连接。

## 视图二：交互式知识图谱

此视图面向家长和复习规划，强调证据、筛选和行动。

- 逐级展开领域、主题和知识点，但允许任何层级出现跨节点关系。
- 支持按学段、年级、学期、教材版本、来源类型、掌握状态、核心素养筛选。
- 支持“短板模式”：折叠稳定掌握节点，突出薄弱节点、前置缺口、相关错题和推荐复习路径。
- 点击节点打开侧边详情：定义、上下位关系、前置知识、教材/训练来源、确认题目数、正确/部分正确/错误分布、最近趋势、相关题目入口。
- 支持“本学期教材”“计算小超市”“补习班”“全部来源”开关，以便看同一知识点被哪些课程重复训练。
- 无法可靠映射的历史标签只出现在“待整理”面板，不散落在正式图中。

## 掌握度与视觉编码

领域归属用节点填充色表示；掌握状态用外圈和边框表示，避免一种颜色承担两个含义：

- 绿色实线：稳定掌握。
- 蓝色实线：基本掌握。
- 橙色粗线：掌握不稳定。
- 红色粗线：明显短板或前置知识缺口。
- 灰色虚线：证据不足。
- 灰色锁定：尚未学习。

掌握率继续以确认题目的加权结果为基础，例如 `(正确 + 0.5 × 部分正确) / 有效作答数`，但必须同时显示证据强度。样本量、证据新鲜度和来源多样性单独编码，不以一次或两次正确直接宣称“已掌握”。趋势只有在近期证据达到最低数量后才显示。

所有正确、错误和部分正确题都保留历史证据；只有经过家长确认、老师批改确认或用户明确接受的模型判卷结果参与状态更新。

## 视觉语言

使用晴子学习助手现有的柔和蓝紫主色，并为四大领域配置协调但可区分的低饱和色。整体保持清爽、亲和、适合小学生长期观看，但不使用幼儿化插画、糖果色堆叠或过度动画。

节点尺寸、字体和触控区域要适合家庭电脑使用。动画只用于展开、聚焦和路径强调，必须尊重减少动态效果设置。图例始终可见，任何状态不得只依赖颜色传达。

## 数据与发布兼容性

- 新图谱模型作为版本化数据层存在，不覆盖既有事实数据库和家长笔记。
- 旧课程 HTML 保留为历史产物；知识库首页改为进入“双视图知识图谱”，并可返回旧课程目录证据页。
- HTML 必须离线可用，不依赖外部 CDN；知识库移动后相对链接仍有效。
- Obsidian 导出继续使用稳定 ID 和普通 Markdown 双向链接。后续 LLMWiki 可以读取同一规范化节点、关系和来源，不需要再次清洗结构。
- 新增六年级、初中、其他教材或培训机构时，只添加数据和映射，不修改渲染器核心逻辑。

## 实施范围

第一阶段完成：

1. 建立可扩展的规范化数学分类、来源、关系和映射状态模型。
2. 将现有北师大版五年级上册目录映射到官方主题；仅录入有可靠依据的细粒度知识点。
3. 生成全景关联脑图和交互式知识图谱两个离线 HTML 入口。
4. 接入经审核的现有掌握证据，隔离跨学科和未匹配标签。
5. 更新知识库首页入口、打印版和 Obsidian 导出。

第一阶段不做：自动抓取并信任所有培训机构目录；自动把名称相似的历史标签强行归类；用模型生成的关系覆盖家长确认事实；安装必须联网的可视化插件。

## 验收标准

1. 两个视图读取同一图谱数据，节点名称、关系、掌握状态和证据数量一致。
2. 全景脑图同时存在层级主枝和可验证的跨主题连接，不能只是卡片列表或纯目录树。
3. 交互图谱可按年级、来源和掌握状态筛选，并能从短板追溯到前置知识与确认题目。
4. “计算小超市”或任意新补习班可通过新增来源数据接入，无需修改渲染器代码。
5. 未确认和疑似跨学科标签不影响数学掌握度；现有错题、确认记录和家长笔记不丢失。
6. 页面可在常用屏幕尺寸下缩放、全屏和打印，图例、状态文字和操作按钮不会因窗口变化消失。
7. 离线打开、重新发布和重复导出保持幂等；完整测试、真实数据库只读回归和打包安装验证通过后才替换桌面版本。
