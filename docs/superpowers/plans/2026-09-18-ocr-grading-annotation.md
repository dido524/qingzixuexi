# OCR 批改与确认入库实施计划

1. 为每题增加归一化答案区域，更新模型提示、传输 Schema、解析和边界校验，并补充契约测试。
2. 调整有效题目视图：模型错误/部分正确在家长确认前显示为待确认；补充仓储迁移和确认入库测试。
3. 新增安全、幂等的批改图与多页 HTML 渲染器，验证原图哈希不变、坐标定位和多页输出。
4. 在普通归档和混合学科拆分工作流中生成批改结果，持久化结果路径并让终态使用有效待确认数量。
5. 复用“本次分析”和“待家长确认”：前者打开批改结果页，后者预选模型建议并优先预览批改图。
6. 运行定向测试和全量测试，构建安装包，备份现有数据库后安装，执行启动冒烟测试并推送 GitHub。
